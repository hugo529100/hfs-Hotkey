Quick Start
Open User panel from the top menu. You will see a Hotkey Help button.
Arrow keys work anywhere: Up/Down scrolls smoothly in the list or preview, Left/Right walks the paging bar.

Tips
Shortcuts are ignored while typing in an input field.
Scrolling uses a rAF velocity engine, so holding an arrow key ramps up and glides to stop instead of jumping.
Press Esc or click outside to close this help.
